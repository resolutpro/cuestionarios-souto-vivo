2. La función de Procesamiento (La lógica corregida)
Esta función toma el JSON crudo del OCR y construye el objeto submission. Fíjate en cómo manejo el occurrenceCounters para los campos repetidos.

TypeScript
export function mapOcrToSubmission(extractedFields: any[]): Record<string, any> {
  const submission: Record<string, any> = {
    // Inicializamos arrays vacíos para los campos de checkbox múltiple
    tipoFinca: [],
    produccionPrincipal: [],
    necesidades: [],
    formacion: [],
    gobernanzaComunidad: []
  };

  // Contadores para campos que se repiten (Sí, No, Baja, Media, Alta)
  const occurrenceCounters: Record<string, number> = {
    "si": 0, "no": 0, "baja": 0, "media": 0, "alta": 0
  };

  // Iteramos sobre CADA campo extraído por el OCR
  for (const field of extractedFields) {
    const rawName = field.field_name || "";
    const rawValue = field.proposed_value || ""; // "☑", "☐" o texto
    const normalizedName = normalizeKey(rawName);

    // ¿Es un campo marcado/seleccionado? 
    // Document AI usa a veces "Selected", "True", "1" o el símbolo "☑"
    const isChecked = rawValue.includes("☑") || rawValue.toLowerCase() === "true" || rawValue === "1" || rawValue.toLowerCase() === "selected";

    // ---------------------------------------------------------
    // CASO 1: Campos dependientes del orden (Sí, No, Baja...)
    // ---------------------------------------------------------
    if (ORDER_DEPENDENT_FIELDS[normalizedName]) {
      const index = occurrenceCounters[normalizedName];
      const mappingList = ORDER_DEPENDENT_FIELDS[normalizedName];

      // Verificamos si aún tenemos mapeos disponibles para este contador
      if (index < mappingList.length) {
        const mapping = mappingList[index];
        
        // Si la casilla está marcada, guardamos el valor
        if (isChecked) {
          submission[mapping.field] = mapping.value;
        }
        
        // ¡IMPORTANTE!: Aumentamos el contador SIEMPRE que aparezca la etiqueta en el documento,
        // esté marcada o no. El OCR detecta la etiqueta "Sí" (checkbox vacío) y luego la etiqueta "Sí" (checkbox lleno).
        // Ambas cuentan para la posición.
        occurrenceCounters[normalizedName]++;
      }
      continue;
    }

    // ---------------------------------------------------------
    // CASO 2: Campos de Array (Multiselección)
    // ---------------------------------------------------------
    // Buscamos coincidencia parcial para frases largas
    const arrayMatch = Object.keys(ARRAY_MAPPING).find(key => normalizedName.includes(key));
    if (arrayMatch) {
      if (isChecked) {
        const mapping = ARRAY_MAPPING[arrayMatch];
        // Evitamos duplicados
        if (!submission[mapping.field].includes(mapping.value)) {
          submission[mapping.field].push(mapping.value);
        }
      }
      continue;
    }

    // ---------------------------------------------------------
    // CASO 3: Campos Enum (Selección Única - Strings largos)
    // ---------------------------------------------------------
    const enumMatch = Object.keys(ENUM_MAPPING).find(key => normalizedName.includes(key));
    if (enumMatch) {
      if (isChecked) {
        const mapping = ENUM_MAPPING[enumMatch];
        submission[mapping.field] = mapping.value;
      }
      continue;
    }

    // ---------------------------------------------------------
    // CASO 4: Campos de Texto Directo
    // ---------------------------------------------------------
    const textMatch = Object.keys(TEXT_FIELDS_MAP).find(key => normalizedName.includes(normalizeKey(key)));
    if (textMatch) {
      const dbField = TEXT_FIELDS_MAP[textMatch];
      // Para texto, queremos el valor propuesto tal cual (ej: "Juan Pérez")
      submission[dbField] = rawValue;
      continue;
    }
  }

  // Limpieza final: Convertir contadores booleanos implícitos
  // Si enProduccion quedó undefined pero detectamos "Sí" o "No", el orden logic ya lo cubrió.
  // Pero para checkboxes booleanos simples como "¿Está en producción?", a veces es mejor usar true/false.
  
  return submission;
}
Puntos clave que arreglan tus errores:
occurrenceCounters[normalizedName]++: La clave del éxito con los campos "Sí"/"No" repetidos es incrementar el contador cada vez que el OCR encuentra la etiqueta, independientemente de si el checkbox está marcado o no. Así mantienes la sincronización con la posición física en el papel.

isChecked logic: En el JSON que subiste, proposed_value es "☑" o "☐". Mi código comprueba explícitamente rawValue.includes("☑"). Si solo comprobabas si existía el campo, siempre daba positivo.

Normalización (normalizeKey): Eliminar tildes y dos puntos (:) hace que "Teléfono de contacto:" coincida con "telefono de contacto".

Mapeo de Arrays: Ahora ARRAY_MAPPING sabe qué valor string específico guardar (ej: "agricola") en lugar de intentar guardar la frase completa del PDF.
